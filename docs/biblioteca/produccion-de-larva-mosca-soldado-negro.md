- La producción de larvas de Mosca Soldado Negro (Hermetia illucens) se centró en definir las condiciones de operación para su crecimiento y desarrollo.
- Se utilizaron residuos orgánicos de alimentos pre-consumo obtenidos de la Secretaría de Integración Social de Bogotá, junto con residuos de la industria cervecera.
- Las proporciones de estos residuos se ajustaron para garantizar diferentes relaciones carbono/nitrógeno (C/N).
- Se implementaron condiciones de operación controladas en términos de temperatura y humedad relativa del aire.
- Se establecieron rangos de operación específicos para el sistema de incubación y el sistema de cultivo.
- La técnica de eclosión se llevó a cabo mediante la "lluvia de crías", donde los huevos caen sobre un soporte con malla.
- El sistema de conteo se basa en la técnica 5-dol, que consiste en contar las larvas cada 12 horas.
- Se utilizó un biorreactor para el sistema de cultivo, diseñado para controlar variables como temperatura y humedad relativa del aire.
- El sustrato inicial se mezcla con residuos orgánicos de la industria cervecera en proporciones específicas (100% residuos cerveceros).
- Se evaluó el diseño de experimentos con diferentes niveles de C/N para determinar las condiciones óptimas para larvas de mayor longitud y peso.
- El sustrato que logró desarrollar larvas con mayor longitud y peso fue el que contenía 100% residuos orgánicos cerveceros.

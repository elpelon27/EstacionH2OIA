## Hechos clave (Qwen local)

- El culvar SCS257 Petuna fue desarrollado por la Epagri/Estación Experimental de Urussanga.
- Se cruzó con el culvar IAC14 para obtener este nuevo culvar, que se obtuvo a través de polinización abierta.
- En 2012, se sembraron sementes y se inocularon con Xanthomonas phaseolis pv. manihos para identificar plantas resistentes.
- Se seleccionó un clone entre las plantas resistentes que demostraron no manifestar la enfermedad bacteriana durante varios años de evaluación.
- El culvar SCS257 Petuna fue validado como clone destacado para la región de Alto Vale do Rio Itajaí, Santa Catarina.
- Se realizó una evaluación regional en dos municipios de la región con dos cosechas consecutivas después de dos ciclos vegetativos (18 meses).
- El culvar SCS257 Petuna se destaca para la producción de farinha y polvilho, siendo indicado para colhizas después de dos ciclos vegetativos.
- Tiene un alto contenido de amido en las raíces, con tolerancia a la bacteriose (Xanthomonas phaseolis pv. manihos).
- Es susceptible al Fusarium solani y presenta raíces con película externa marrom clara, sin pedúnculo, polpa blanca y forma cilíndrica.
- La facilidad de arranque es moderada después de dos ciclos vegetativos.
- En la evaluación en Trombudo Central, SC, el culvar SCS257 Petuna produjo 48.5 t/ha de raíces y 16.9 t/ha de amido en las safras 2019/21 y 2020/22.
- El culvar SCS257 Petuna se recomienda para la región 2A: Alto Vale do Rio Itajaí, según el zoneamiento climático para la cultura de mandioca en Santa Catarina.
- El material de propaga (ramas) del culvar SCS257 Petuna estará disponible por oferta pública.
- La Epagri/Estación Experimental de Urussanga está ubicada en Urussanga, Santa Catarina.

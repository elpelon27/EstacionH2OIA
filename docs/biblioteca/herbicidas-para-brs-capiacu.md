## Hechos clave (Qwen local)

- La empresa Embrapa Gado de Leite está trabajando en la búsqueda de un herbicida para el BRS Capiaçu.
- Actualmente, no existe ningún herbicida registrado por el MAPA para este tipo de cultivo.
- Se han presentado resultados promissores con algunas combinaciones de herbicidas.
- La mezcla de atrazina + S-Metolachlor en la fase pre-emergencia controla tanto folia estrecha como larga.
- Esta mezcla está disponible en el mercado y se utiliza para controlar plantas daninhas en cultivos de maíz, que también puede ser aplicada al BRS Capiaçu.
- El productor tiene la opción de usar una mezcla personalizada: atrazina + 1.5 L de S-Metolachlor por hectárea (ha) después del plantio.
- Para el control en fase post-emergencia, se puede utilizar 2,4 D y su mezcla con Picloran (Tordon antiguo) directamente sobre el capim.
- También se puede usar glifosato en jato dirigido para controlar la folia estrecha, evitando así que afecte al BRS Capiaçu.
- Es necesario verificar si los productos químicos están registrados por el MAPA para uso en capim-elefante antes de su aplicación.
- Para comprar herbicidas, es necesario tener una receta prescrita por un agrónomo.
- Se recomienda buscar la ayuda de un Engenheiro agrônomo en EMATER local o en los organismos de extensión rural cercanos.
- La Embrapa Gado de Leite está trabajando en este problema y busca soluciones para el BRS Capiaçu.
